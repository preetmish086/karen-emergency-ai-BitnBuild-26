# Karen's Ear

## AI Emergency Dispatch Assistant

Karen's Ear converts chaotic emergency reports into a structured and prioritized picture of where help is needed.

### Pipeline

```text
Raw Emergency Reports
        ↓
Relevance Detection
        ↓
NLP Extraction
        ↓
Severity + Actionability
        ↓
Credibility Assessment
        ↓
Incident Clustering
        ↓
Cross-Report Corroboration
        ↓
Priority Engine
        ↓
Emergency Dashboard
```
